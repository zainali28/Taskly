# ✅ Taskly  

A **React Native** task management app designed to help users stay organized and productive. Built with **React Native, Firebase, and Context API**, this app enables users to manage tasks efficiently with an intuitive interface.  

## 🚀 Features  
✅ **Task Creation & Management** – Add, edit, and delete tasks easily.  
✅ **Task Prioritization** – Organize tasks by priority levels.  
✅ **Reminders & Notifications** – Stay on track with scheduled reminders.  
✅ **Sync with Firebase** – Access tasks from multiple devices.  
✅ **Smooth UI & Performance** – Optimized for fast, responsive navigation.  

## 🛠️ Tech Stack  
- **Frontend**: React Native, Expo  
- **Backend**: Firebase (Auth, Firestore)  
- **State Management**: React Context API

## 📦 Installation  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/zainali28/Taskly.git  
   cd Taskly  
   ```  
2. Install dependencies:  
   ```bash  
   npm install  
   ```  
3. Start the app:  
   ```bash  
   expo start  
   ```
